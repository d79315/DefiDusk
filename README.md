# DefiDusk

Decoupled cross-chain engine enabling real-time data processing, auto-scaling, and load balancing on a decentralized platform.

DefiDusk is built to be simple and practical, focusing on doing one thing well.

**Why DefiDusk?**

- Decoupled cross-chain engine enabling real-time
- data processing, auto-scaling, and load
- balancing on a decentralized platform

## Key Features

- Decoupled cross-chain engine enabling real-time
- data processing, auto-scaling, and load
- balancing on a decentralized platform

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/DefiDusk.git`
2. `cd DefiDusk`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure DefiDusk, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
